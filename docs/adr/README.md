# Architecture decision records

Short decisions live in the table in [`live_class.md` §15](../../live_class.md). When a
decision needs more than a row (context, options weighed, consequences), add a file here
named `NNNN-short-title.md` using the template below and link it from the table.

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context

## Decision

## Consequences

## Alternatives considered
```
